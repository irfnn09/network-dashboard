# ⬡ NetWatch — Network Monitor Dashboard

A lightweight network monitoring dashboard built with Python & Flask.
Monitor the status of your network devices in real-time from your browser.

## 🚀 Features
- Real-time ping monitoring
- Clean, minimal dashboard UI
- Online/Offline status badges
- Device summary overview
- Easy to add/remove devices

## 🛠️ Tech Stack
- Python 3
- Flask
- HTML & CSS

## ⚙️ Setup & Installation

1. Clone the repo
   git clone https://github.com/irfnn09/network-dashboard.git

2. Install dependencies
   pip install flask

3. Run the app
   python app.py

4. Open browser
   http://127.0.0.1:5000

## 📡 Add Your Own Devices
Open app.py and edit the devices list:
   {"name": "My Device", "host": "192.168.1.x"},
